Only Czech linked-recipe uploads and TM7 UI have user acceptance. All other entries remain experimental: public route checks and mock tests do not establish live login, entitlement, upload or device behavior. Each site currently uses one default route language. Mainland China phone login is not supported. No automatic cross-market fallback occurs.
